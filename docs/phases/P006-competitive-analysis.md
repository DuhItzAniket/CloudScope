# P006 — Competitive analysis

Status: DONE     Date: 2026-10-04     Commit: (this commit)

## Objective
Compare CloudScope's scope with the products its users already know (SharpCap, AMCap, FireCapture, N.I.N.A., KStars/Ekos/INDI, indi-allsky, AllSky, ASCOM Alpaca), decide what to adopt, and identify what genuinely differentiates CloudScope.

## Requirements covered
Amends the SRS to v1.1 (10 new requirements, FR-REC-02 tightened); resolves SRS open question Q3 (INDI/Alpaca).

## Design notes
- Research was done from official documentation, source code and release APIs; every claim carries a source and unconfirmed items are listed explicitly (`docs/research/P006_competitive_analysis_sources.md`, §5).
- Decisions are summarised in `docs/research/P006_competitive_analysis.md` (D1–D7).
- Plan rows updated: P020 (raw/ROI/binning), P027 (AstroTIFF, FITS keyword set, WCS), P028 (SER v3 round-trip, keograms, star trails), P029 (day/night profiles), P036 (preview-only stretch), P055 (Alpaca client, optional INDI client), P084 (Alpaca server), P085 (MQTT + Home Assistant).
